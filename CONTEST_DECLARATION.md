# Contest Declaration

**Project:** TabulaSage — an offline, open-source-AI data profiler.

**Originality:** TabulaSage is an original work by Zhiyilang, built for the
Hacktoberfest 2026 Open-Source AI Challenge (Week 2). It does not copy code
from other projects. It relies only on widely-used open-source libraries
(scikit-learn, NumPy), all of which are credited in `requirements.txt` and the
README.

**Open-source at its core:** The intelligence in TabulaSage is the open-source
scikit-learn library (IsolationForest for anomaly detection and tree-based
models for interpretable classification). No closed API, no hosted model, no
API key, no telemetry. Every byte of the user's data stays on their machine.

**Compliance:** This project contains no malicious code, no tracking, no
scraping, and no personal data. The bundled sample CSV is synthetic.
